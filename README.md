# MockMate
Java 21 + Spring Boot + Spring Data JPA/Hibernate + MySQL + HTML/CSS/JavaScript.

## Run
1. Start MySQL in Laragon.
2. Run database/schema.sql in MySQL Workbench.
3. If your MySQL root password is not blank, set it in src/main/resources/application.properties.
4. From the project root: mvn spring-boot:run
5. Open frontend/index.html.

This is the working MVP foundation. Authentication, persisted interviews, scoring, coding challenges, analytics, resume-aware questions and AI feedback are the next development phases.
